# Guía de contribución — Nexora IA

- Explica las decisiones técnicas para que el proyecto sirva como aprendizaje práctico.
- Mantén la bitácora en `docs/BITACORA_APRENDIZAJE.md` al añadir hitos comprobados.
- No incluyas bases de datos locales, mensajes, credenciales, instaladores ni contexto personal.
- El servidor debe permanecer vinculado a `127.0.0.1` salvo una decisión explícita de diseño.
- No afirmes que una función está comprobada si no se ejecutó.
- Los cambios deben conservar compatibilidad con Node.js y SQLite.
