# Contexto público de Nexora IA

Nexora IA es un proyecto personal en desarrollo para aprender construyendo una asistente local. Combina una interfaz web, una API en Node.js y Express, persistencia SQLite y un modelo servido por Ollama.

## Objetivos de aprendizaje

- Comprender el recorrido de una petición desde el navegador hasta una API y la base de datos.
- Practicar SQL y modelado con un historial real de conversaciones.
- Aprender a integrar un modelo de lenguaje local mediante una API.
- Documentar cada hito con una práctica y una forma de comprobarlo.

## Alcance actual

La aplicación se ejecuta localmente. El servidor limita conexiones a loopback. Las conversaciones se almacenan en SQLite. El proveedor de modelo puede configurarse con `OLLAMA_HOST` y `OLLAMA_MODEL`.

Este archivo contiene únicamente contexto técnico público. Las preferencias personales y datos privados se mantienen fuera de la publicación.
